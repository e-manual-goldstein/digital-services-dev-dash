## Design notes

### How to add an idea

1. Add a row to **Ticket summary** with status **Idea**.
2. Add a matching `### IDE-NNN` section with a one-line description.
3. Add the row to `backlog.md` → **Ideas** section.
4. When ready to build: create a new epic file (e.g. `CAL-calendar.md`), move the idea into a real ticket, remove from Ideas.

### Prompting template

> I have an idea: \<describe the feature\>. Add it to IDE-ideas and backlog Ideas.
